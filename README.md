# Devil-Defense X
this is a roblox tower defense game, similar to popular titles like 'bloons td6' by Ninja kiwi or the roblox fan favorite, 'tower defense simulator' by Paradoxom games.

in devil defense x, i feature my own unique methods to combat common issues i found in other tower defense titles and added my own twist with the popular anime series Chainsaw Man

https://www.roblox.com/games/88195967000519/Devil-Tower-Defense
https://youtu.be/5kC2MoRXbQk

## Current Systems
enemy spawning and custom pathfinding using tween service (lets me use curved paths)

basic ui for testing the enemy spawning and pathfinding

placeable units (not super complicated yet, just basic placement)

placed units can be clicked to open a ui overview menu, and has an upgrade tree button to view their upgrade tree

most everything is a work in progress, but ive tried my best to make it playable to see what ive done.

**(it should work fine on most computers, as it is in early development, only computer is supported. i did not test nor code intending any other platform)**
